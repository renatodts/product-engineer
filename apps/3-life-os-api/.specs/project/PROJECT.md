# Life OS — api

**Complexity score:** 35

## Purpose

Backend for a personal "operating system" that unifies tasks, notes, habits, and goals into a
single planning layer with AI-assisted prioritization and daily review. Aims to be the system of
record for an individual's day-to-day execution.

## Stack

- Framework: NestJS
- Port: 4003
- Test runner: Jest + supertest
- Module system: CommonJS
