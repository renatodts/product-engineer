# Personal ERP — api

**Complexity score:** 85

## Purpose

Backend for an all-in-one personal enterprise resource planner spanning finances, projects,
assets, contacts, documents, and scheduling. Unifies every personal operational domain into one
integrated, AI-orchestrated system of record.

## Stack

- Framework: NestJS
- Port: 4008
- Test runner: Jest + supertest
- Module system: CommonJS
