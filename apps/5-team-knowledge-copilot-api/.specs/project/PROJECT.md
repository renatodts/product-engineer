# Team Knowledge Copilot — api

**Complexity score:** 60

## Purpose

Backend for a retrieval-augmented assistant that indexes a team's documents, wikis, and chat
history and answers questions with cited sources. Provides search, ingestion, and conversational
endpoints over an organization's knowledge base.

## Stack

- Framework: NestJS
- Port: 4005
- Test runner: Jest + supertest
- Module system: CommonJS
