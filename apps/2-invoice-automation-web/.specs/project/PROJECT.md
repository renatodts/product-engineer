# Invoice Automation — web

**Complexity score:** 25

## Purpose

A workspace for ingesting invoices, extracting line items, and routing them through approval.
The web app lets users upload documents, review extracted fields, and track payment status.

## Stack

- Framework: Next.js (App Router)
- Port: 3002
- Test runner: Vitest (unit/component), Playwright (E2E)
- Module system: ESM
