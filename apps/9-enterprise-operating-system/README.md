# Enterprise Operating System — web

**Complexity score:** 100

## Purpose

An enterprise-wide platform unifying operations, finance, HR, and analytics across departments and roles. The web app is the central console for workflows, dashboards, and AI-driven decision support at organizational scale.

## Complexity Breakdown

- **Domain complexity:** High — it spans virtually every enterprise domain with deep, regulated, role-specific rules.
- **Architecture complexity:** High — many bounded contexts and services integrate behind a unified, multi-tenant front end.
- **Infrastructure complexity:** High — multi-tenant scale, strict security and compliance, and high availability are core requirements.

## AI Usage

AI powers cross-department insights, workflow automation, and natural-language operations across the organization. AI-assisted development is essential to compose this large, multi-module surface.
