# Enterprise Operating System — web

**Complexity score:** 100

## Purpose

An enterprise-wide platform unifying operations, finance, HR, and analytics across departments
and roles. The web app is the central console for workflows, dashboards, and AI-driven decision
support at organizational scale.

## Stack

- Framework: Next.js (App Router)
- Port: 3009
- Test runner: Vitest (unit/component), Playwright (E2E)
- Module system: ESM
