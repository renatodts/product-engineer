# AI Flashcards — web

**Complexity score:** 10

## Purpose

A study companion that turns notes and source material into spaced-repetition flashcards. The web
app surfaces decks, review sessions, and AI-generated card suggestions.

## Stack

- Framework: Next.js (App Router)
- Port: 3001
- Test runner: Vitest (unit/component), Playwright (E2E)
- Module system: ESM
