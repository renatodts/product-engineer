# Personal ERP — web

**Complexity score:** 85

## Purpose

A unified resource-planning system for an individual or small operation, spanning finances,
projects, assets, and contacts. The web app ties these modules together with shared reporting and
automation.

## Stack

- Framework: Next.js (App Router)
- Port: 3008
- Test runner: Vitest (unit/component), Playwright (E2E)
- Module system: ESM
