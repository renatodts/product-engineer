# AI Flashcards — api

**Complexity score:** 10

## Purpose

Backend for an AI-assisted flashcard study tool that turns notes or topics into question/answer
decks and schedules reviews. Exposes simple CRUD endpoints for decks and cards plus an AI
generation endpoint.

## Stack

- Framework: NestJS
- Port: 4001
- Test runner: Jest + supertest
- Module system: CommonJS
