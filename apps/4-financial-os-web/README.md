# Financial OS — web

**Complexity score:** 50

## Purpose

A personal financial command center aggregating accounts, transactions, budgets, and forecasts. The web app delivers categorized spending views, budget tracking, and cash-flow projections.

## Complexity Breakdown

- **Domain complexity:** Medium — accounts, transactions, categorization, and budgeting carry meaningful financial-logic rules.
- **Architecture complexity:** Medium — account aggregation, categorization, and forecasting span several coordinated services.
- **Infrastructure complexity:** Medium — recurring sync jobs and secure handling of financial data raise the bar.

## AI Usage

AI auto-categorizes transactions, detects unusual spending, and generates cash-flow forecasts. AI-assisted development supports the data-dense dashboard work.
