# Financial OS — web

**Complexity score:** 50

## Purpose

A personal financial command center aggregating accounts, transactions, budgets, and forecasts.
The web app delivers categorized spending views, budget tracking, and cash-flow projections.

## Stack

- Framework: Next.js (App Router)
- Port: 3004
- Test runner: Vitest (unit/component), Playwright (E2E)
- Module system: ESM
