# Life OS — web

**Complexity score:** 35

## Purpose

A personal operating system unifying tasks, notes, habits, and goals into one workspace. The web
app provides dashboards and views that connect daily actions to longer-term objectives.

## Stack

- Framework: Next.js (App Router)
- Port: 3003
- Test runner: Vitest (unit/component), Playwright (E2E)
- Module system: ESM
