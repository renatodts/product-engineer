# Life OS — web

**Complexity score:** 35

## Purpose

A personal operating system unifying tasks, notes, habits, and goals into one workspace. The web app provides dashboards and views that connect daily actions to longer-term objectives.

## Complexity Breakdown

- **Domain complexity:** Medium — spans several productivity domains (tasks, notes, habits) that must interrelate coherently.
- **Architecture complexity:** Medium — multiple feature modules and an AI assistant share a unified data model.
- **Infrastructure complexity:** Low — primarily a personal-scale app over a single backend and datastore.

## AI Usage

An AI assistant summarizes the day, suggests priorities, and links related notes and tasks. AI-assisted development helps compose the many interconnected views.

## Future Roadmap

- [ ] Unified dashboard for tasks, notes, and habits
- [ ] AI daily-planning and prioritization assistant
- [ ] Goal tracking linked to recurring habits
